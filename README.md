# YouPlay

Красивый десктопный клиент YouTube Music для Windows.

- **5 стилей:** Liquid Glass, Material You, Android 4 Holo, Windows 7 Aero, классический
- **Синхронный текст песен:** субтитры с караоке-подсветкой, боковая панель и полноэкранный режим (Ctrl+L, Ctrl+J)
- **Визуализатор под бас:** полосы, волна или свечение; фон реагирует на музыку
- **Встроенный блокировщик рекламы:** сетевой фильтр и удаление рекламы из плеера
- **Вход в аккаунт Google**, кнопки управления в миниатюре на панели задач, медиаклавиши
- **Автообновление:** при каждом запуске проверяет GitHub Releases

## Установка
Скачайте `YouPlay-Setup-x.y.z.exe` из [Releases](../../releases/latest) и запустите. Установка проходит в один клик, ярлык появится на рабочем столе.

> Установщик не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение: нажмите «Подробнее» → «Выполнить в любом случае».

## Разработка
```
npm install
npm start          # запуск
npm run dist       # сборка установщика
npm run release    # сборка + публикация релиза на GitHub (нужен GH_TOKEN)
```
Чтобы выпустить обновление, поднимите `version` в `package.json` и запустите `npm run release`.

Горячие клавиши: Ctrl+L — текст, Ctrl+J — субтитры, Ctrl+, — настройки, F11 — полный экран.

Тексты песен берутся из [LRCLIB](https://lrclib.net).
