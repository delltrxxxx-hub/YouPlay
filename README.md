# YouPlay

Красивый клиент YouTube Music для Windows.

YouPlay — отдельное приложение со своим окном и значком. Внутри работает WebView2, встроенный в Windows движок Microsoft Edge, и расширение YouPlay. Поэтому вход в аккаунт Google проходит как в обычном браузере, без обходов.

- **6 стилей:** Studio, Liquid Glass, Material You, Android 4 Holo, Windows 7 Aero, классический
- **Экран «Сейчас играет»:** большая обложка, плавный прогресс, кнопки управления и синхронный текст (нажмите на обложку в плеере)
- **Субтитры с караоке-подсветкой.** Тайминги сами подстраиваются под slowed и sped up версии, а кнопки ±0,5 с позволяют подвинуть текст вручную
- **SoundCloud в общей очереди:** вставьте ссылку на трек или плейлист (кнопка с облаком или просто Ctrl+V). Треки играют сразу после текущего трека YouTube Music и помечены значком источника
- **Единый поиск:** один список треков из YouTube Music и SoundCloud со значками источника, всё играет в общей очереди
- **«Любимое»:** лайки YouTube Music и SoundCloud в одном плейлисте, новые сверху (для SoundCloud нужно один раз войти в аккаунт)
- **Треки вместо клипов:** если включился клип, YouPlay сам переключает на аудиоверсию; предложения Premium закрываются сами
- **F11:** полноэкранный режим окна
- **Лайк и «не нравится» прямо в плеере:** сердечко сохраняет трек в ваш аккаунт YouTube Music или SoundCloud, разбитое сердечко убирает трек навсегда (список «Не нравится» в очереди)
- **Таймер сна**, вход в аккаунты прямо в настройках
- **Визуализатор под бас:** полосы, волна или свечение
- **Блокировка рекламы:** фильтр запросов и удаление рекламы из плеера
- **Плавная полоска прогресса**, скрываемая правая панель, поиск с читаемым списком подсказок
- **Обновления в один клик:** при запуске YouPlay сообщает о новой версии, кнопка «Обновить сейчас» скачивает её и перезапускает приложение. Вход и настройки сохраняются

## Android
Скачайте `YouPlay-Android-x.y.z.apk` из [Releases](../../releases/latest) и установите (разрешите установку из этого источника). Тот же дизайн и функции в мобильном виде: нижние вкладки, мини-плеер, «Сейчас играет» со свайпом, уведомление и экран блокировки, фоновое воспроизведение, обновления из приложения. **Моя музыка** — плеер файлов с телефона, работает полностью без интернета; без сети YouPlay сам открывает его.

## Установка
Скачайте `YouPlay-Setup-x.y.z.exe` из [Releases](../../releases/latest) и запустите. Установка проходит в один клик, без прав администратора, ярлык появится на рабочем столе. Нужен WebView2 Runtime, он уже есть в Windows 11 и в обновлённой Windows 10.

> Установщик не подписан, поэтому SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Сборка
```
npm install
npm run build      # dist/YouPlay-Setup-<версия>.exe
npm run release    # опубликовать релиз на GitHub (нужен gh)
```
Для новой версии поднимите `version` в `package.json`, затем выполните `build` и `release`.

Горячие клавиши: Ctrl+L — текст, Ctrl+J — субтитры, Ctrl+, — настройки, Ctrl+K — «Сейчас играет», F11 — полный экран, Esc — закрыть.

Тексты песен берутся из [LRCLIB](https://lrclib.net).
