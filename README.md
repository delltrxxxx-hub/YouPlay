# YouPlay

Красивый клиент YouTube Music для Windows.

YouPlay открывает YouTube Music в отдельном окне Microsoft Edge (без вкладок и адресной строки) со своим профилем и встроенным расширением YouPlay. Поэтому вход в аккаунт Google работает как в обычном браузере, без обходов и ограничений.

- **6 стилей:** Studio, Liquid Glass, Material You, Android 4 Holo, Windows 7 Aero, классический
- **Экран «Сейчас играет»:** большая обложка, плавный прогресс, кнопки управления и синхронный текст (нажмите на обложку в плеере)
- **Субтитры с караоке-подсветкой.** Тайминги сами подстраиваются под slowed и sped up версии, а кнопки ±0,5 с позволяют подвинуть текст вручную
- **Визуализатор под бас:** полосы, волна или свечение
- **Блокировка рекламы:** фильтр запросов и удаление рекламы из плеера
- **Плавная полоска прогресса**, скрываемая правая панель, поиск с читаемым списком подсказок
- **Автообновление:** при каждом запуске YouPlay проверяет GitHub Releases, скачивает новую версию в фоне и тихо её устанавливает

## Установка
Скачайте `YouPlay-Setup-x.y.z.exe` из [Releases](../../releases/latest) и запустите. Установка проходит в один клик, без прав администратора, ярлык появится на рабочем столе. Нужен Microsoft Edge, он есть в каждой Windows 10/11.

> Установщик не подписан, поэтому SmartScreen может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Сборка
```
npm install
npm run build      # dist/YouPlay-Setup-<версия>.exe
npm run release    # опубликовать релиз на GitHub (нужен gh)
```
Для новой версии поднимите `version` в `package.json`, затем выполните `build` и `release`.

Горячие клавиши: Ctrl+L — текст, Ctrl+J — субтитры, Ctrl+, — настройки, Esc — закрыть.

Тексты песен берутся из [LRCLIB](https://lrclib.net).
